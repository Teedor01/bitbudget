Bit Budget

Every verifier sees only a small answer. Bit Budget tracks what all of them can collectively learn.

Local simulation, not a product. Everything runs only on this computer. The “anchor” is an in-memory test double (no blockchain), the “sealer” does not encrypt, and the credential is a mock (no real income verification). All amounts are US dollars ($).

On-chain anchor: NEAR testnet

Anyone can check this without credentials. It is a read-only view of the deployed contract. It cannot submit writes: only this server’s signing account can.
